
# Authentication Upgrade v2.2

## First Login
- User signs up with Name, Username, Email, Password and a 4-digit PIN.

## Daily Access
- The app remembers the signed-in user.
- Users unlock Scrappy with their 4-digit PIN.
- Full email/password is only required after logging out.

## Forgot PIN
1. Tap **Forgot PIN**.
2. Enter Username and Email.
3. A PIN reset request is sent to the administrator email (currently configured as veilorse@gmail.com for the prototype).
4. Admin reviews the request.
5. If approved, the user creates a new PIN.
6. If rejected, access remains locked.
